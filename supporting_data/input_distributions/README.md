# Recorded inputs and report collections

The categorical_inputs.csv and numeric_inputs.csv files contain the complete displayed distributions for Train, Calibration, Test and Targets. report_collections.csv and unavailable_inputs.csv accompany Supplementary Tables S4 and S5. Their original notes and display definitions are retained in display_definitions.json. Rounded summaries are descriptive; use the full-precision files for numerical work.

The six full-precision CSV files preserve the existing population counts, predictor dictionary, distributions and missingness records. The dictionary identifies primary inputs, the seven-field extension and 24 landscape candidates. Numeric summaries use available-value denominators. Category counts retain source-missing Unknown values and use full-population denominators. Explicit unknown codes and rejected numeric values contribute zero to unavailable values in these retained collections. Missingness reasons are not inferred from these counts.

Nineteen population labels overlap. Temporal training, calibration and test collections partition the national collection. The selected eight airports remain excluded from national fitting and calibration. Recent targets are a subset of the full target collection. The all-airport missingness file retains all 1,383 airports, including sparse collections. Full distributions for every other individual airport and auxiliary sensitivity inputs are outside this summary collection.

Landscape measurements are complete after the eligibility screens. They are repeated across eligible reports from the same airport-year, so these distributions describe report-weighted inputs. The 24 candidate landscape representations are retained regardless of which representation a model selected. All preprocessing parameters remain learned from training data only. Input metadata records rules, units, denominators and file roles. These local files are prepared for packaging and have not been publicly released.
