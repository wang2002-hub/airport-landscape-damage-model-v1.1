# Reference numbering across documents

The manuscript and Supplementary Information have independent reference lists. Use the stable key or DOI in document_citation_map.csv to match entries between them. The reference_registry.json file defines the registry numbering used by the supporting technical records.

Bracketed citations in supporting_data/canopy_context/measurement_context.json, supporting_data/source_computation/source_replay_methods.md, supporting_data/source_computation/source_timing_and_replay_scope.json and supporting_data/uncertainty_catalogue/uncertainty_methods.md use the registry namespace, not either document-specific numbering sequence. This includes quoted source paragraphs and the bibliographic labels within the two Markdown methods notes. The canopy source is registry 39. The source-computation records cite registry 40, 41 and 42. The uncertainty methods cite registry 29, 30 and 31. These four files contain ten citation occurrences and six bibliography labels in total. The registry includes all 42 sources and retains their source bibliographic text. It supports citation resolution; it is not evidence that every bibliographic field has been independently verified. Numeric array indices and bracketed year ranges in other supporting files are data or code notation, not citations. Interpret each entry using its declared namespace and match the stable key before comparing numbers across documents. The two document lists contain 36 and 26 entries, respectively, with 20 shared sources.
