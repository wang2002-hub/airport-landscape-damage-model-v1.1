# Table and supporting-record references

Table S1 through Table S30 identify current supplementary tables. SRC-S identifiers identify supporting source records and must not be read as current table numbers. record_index.json gives source record locations and the current table map. A topic correspondence does not establish identical populations or statistical scope.

Source-definition JSON files preserve their documented figure and citation namespaces. Reader-facing Markdown locators use current table numbers where a corresponding table exists. Airport codes, original analytical data and source citation numbers are unchanged.
